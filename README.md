# Age Calculator

A simple and intuitive web application that calculates a person's exact age in years, months, and days based on their birth date.

## Features
- Calculates precise age using the user's birth date.
- Accounts for months and days, giving a detailed output.
- Clean and modern user interface styled with CSS.
- Responsive design.
- Includes simple input validation to ensure valid dates.

## Technologies Used
- HTML5
- CSS3
- JavaScript (Vanilla)

## How to Use
1. Open `index.html` in your favorite web browser.
2. Select your birth date from the date picker.
3. Click on the "Calculate Age" button.
4. Your exact age will be displayed below the button!

## Running locally
Simply clone or download this repository, and open the `index.html` file in a web browser. No local server or build tools are required.
